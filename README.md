# 安宁礼仪与公墓运营服务

这是一个供殡仪馆、公墓和合作医疗机构使用的 Python 后端服务，统一管理生前契约、逝者业务档案、遗体保管交接、送别厅与火化设备预约、服务订单、墓位权属、账单收款和审计时间线。系统把容易产生争议的交接、排程、收费与长期合同义务保存在本地 SQLite 中，支持在单个 Linux 应用容器内离线运行。

## 运行环境

- Python 3.11
- FastAPI 与 Uvicorn
- SQLite 3，由 Python 标准库提供

## 安装

依次执行 python -m venv .venv、source .venv/bin/activate、python -m pip install -e ".[dev]"。可通过 PEACEFUL_CARE_DATABASE_PATH 指定数据库文件，默认写入项目的 data 目录。

## 初始化与启动

先执行 python -m app.cli init-db 和 python -m app.cli check-db，再用 uvicorn app.main:app --host 0.0.0.0 --port 8432 启动。健康检查为 GET /api/system/health。殡葬业务接口位于 /api/mortuary，涵盖档案、交接、资源、预约、服务订单、墓位权属、账单和时间线。生前契约接口位于 /api/preneed，涵盖签约冻结、分期与收款、版本变更、暂停恢复、解除退款、受益人转让、死亡转换和时点责任重放。

## 测试与编译检查

测试命令：python -m pytest

编译命令：python -m compileall -q app tests

API 与 CLI 冒烟命令：python -m app.cli smoke、python -m app.cli mortuary-demo、python -m app.cli preneed-demo

## 目录结构

- app/preneed：多年期生前契约领域（版本、分期、资金、会计事件、状态机、死亡转换）
- app/mortuary：档案、保管交接、资源排程、权属和账单领域
- app/api：登录、角色、审计及系统管理接口
- app/core：时钟、安全、异常、隐私与分页能力
- app/repositories：通用身份和审计数据访问
- app/services：会话、权限、后台任务及维护服务
- tests：领域、接口、异常路径和身份回归测试

## 生前契约生命周期约定

- 签约时冻结服务清单、单价依据（价目表版本）、分期计划与退款规则；合同负债与应收契约款按全额登记复式会计分录。
- 任何服务变更都生成新版本行，旧版本只追加不修改；新版本必须登记客户确认人与确认凭证后才生效，未确认草案可废弃。
- 分期实收按到期顺序自动分摊（也可指定期次），收款流水号全局唯一并幂等；逾期由经办、主管或批处理标记，逾期期次补齐后自动恢复有效。
- 暂停需客户服务主管权限且记录客户知情；暂停期间禁止收款。解除需经办与审批分离（财务主管），按退款规则计算可退金额与违约金，生成应退履约款，出纳支付后结清。
- 受益人转让保留原契约全部历史（状态转为已转让），另建继承契约，冻结清单与价格不变，已缴资金与未缴余额通过“转让待清算”科目平移。
- 仅在受益人死亡后可转换：按最新已确认版本价格生成逝者档案与已确认服务订单，转换按契约与业务档案双重唯一约束防重复，并保留未履约余额继续收缴。
- GET 契约详情返回资金差额、可退估算、下一步动作与完整版本历史；GET /snapshot?as_of= 重放截至任一时点的状态、合同责任、已收资金和下一步动作。
- 敏感动作按岗位角色鉴权：preneed_clerk（签约/变更/转让申请）、customer_service_lead（暂停/转让批准/死亡转换复核）、finance_cashier（收款/退款支付）、finance_manager（解除审批）、system_batch（逾期批处理）。

## 一致性约定

SQLite 连接启用外键、WAL、忙等待和即时事务。业务档案采用外部编号去重，保管交接与预约保留幂等键，服务订单开票后不可再次开票，支付流水不能重复分配。关键状态变化同时写入领域时间线；会话令牌仅保存摘要，审计记录不会保存明文密码或令牌。
